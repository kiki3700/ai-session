# ai-session

AI 기초 세션(9주)에서 화면에 띄우는 자료입니다. 각 파일은 외부 의존성 없이 혼자 도는 HTML 한 장입니다.

**전체 목록 → https://kiki3700.github.io/ai-session/**

| 회차 | 파일 | 무엇 |
|---|---|---|
| 1 | `session-01-모눈종이.html` | 참가자 인쇄물. A4 한 장 |
| 1 | `session-01-추세선.xlsx` | 6번 엑셀 시연용 |
| 2 | `session-02-경사하강.html` | U자 골짜기 · 안개 속 한 걸음 · 보폭 · 제곱하는 이유 |
| 3 | `session-03-relu.html` | 음수는 0으로 · 꺾이는 자리 · 여러 개 더하기 |
| 4 | `session-04-파라미터.html` | 파라미터 세기 · 17개 통과 · 3×3 탐지기 |
| 5 | `session-05-softmax.html` | 순진한 방법 · Softmax · 3점 차이 · OOD |

`pdf/` 는 각 자료를 인쇄용으로 뽑아둔 것입니다.

진행 대본과 회차별 노트는 Obsidian vault 의 `study/ai/session/` 에 있습니다. 이 저장소는 화면 자료만 둡니다.

검색 노출은 `robots.txt` 와 각 페이지의 `noindex` 로 막아뒀습니다. 공개 저장소이므로 URL 을 아는 사람은 볼 수 있습니다.
